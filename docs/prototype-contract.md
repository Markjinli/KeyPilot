# HTML 原型交互契约

基准文件：[`../../handheld-key-mapper-preview.html`](../../handheld-key-mapper-preview.html)  
审查时 SHA-256：`A7090784C182A4FD92377716F7E2FEF2D184AC2C57531C386A02C3AEB7123B7A`

WinUI 实现必须把原型作为交互基线；只有浏览器演示数据和伪输入需要替换为真实状态。

## 页面骨架

- `212` 有效像素侧栏：品牌、采集/映射导航、映射计数、当前编辑方案、方案管理入口和安全退出提示。
- `62` 高顶栏：面包屑、输入服务状态、全局映射开关。
- 最大宽 `1540` 的工作区：状态带、完整键盘、手柄、10 个特殊键槽位、底部运行状态。
- `<1120` 时下方面板改单列；`<760` 时侧栏折叠成顶部双导航。

## 同一画布的两种模式

采集和映射必须共用同一批输入节点，不能维护两套键盘或两套映射状态。

### 采集模式

- 显示输入来源、友好名称、原始代码、位置、状态及最多三条最近输入。
- 按键按下后高亮约 `220ms`。
- 已映射节点仅使用薄荷色描边和右下状态点，不遮挡采集信息。
- 显示清空历史和采集开关。

### 映射模式

- 状态带显示“来源 → 目标”、动作类型、触发条件和屏蔽策略。
- 已映射节点使用薄荷色实底并显示目标摘要；未映射节点降低至 `0.4` 透明度。
- 当前节点显示白色 `2px` 外框。
- 隐藏采集开关和清空历史；没有选择时默认选中 Space。

## 输入面板

- 键盘保持 104 键结构，最小宽 `1120`，窄窗口横向滚动。
- 手柄包含 LB/RB、LT/RT、View/Menu、方向键、ABXY、L3/R3，以及左右摇杆各四个推动方向。LT/RT 与摇杆方向采用带滞回的阈值输入，不把模拟噪声直接当作重复按键。
- 特殊键固定 10 槽。未知键盘扫描码可自动占用空槽；Raw HID 为避免噪声误报，必须先点击一个空槽再采集。
- Raw HID 采集要求同一报告完成“首次变化 → 恢复基线 → 再次出现相同变化”，10 秒超时。确认后显示原始字节变化并命名为“未命名特殊键”，不得强制弹窗。
- Raw HID 槽位必须明确标注为低置信度、待校准结果；当前没有解析 `ReportId`，不能把字节模式宣称为确定按钮语义。
- 所有输入节点都必须具有稳定 UI ID；UI 简写为 `kind:id`。映射草稿保存捕获到的完整 `InputSource`，并随活动方案、映射与特殊键名称持久化到 `%LOCALAPPDATA%\KeyPilot\config.json`。

## 右键菜单

键盘、手柄和特殊键统一提供：

1. 创建或编辑映射。
2. 测试并查看原始代码。
3. 重命名特殊键（仅非空特殊键）。
4. 清除映射（无映射时禁用）。

菜单应限制在窗口范围内；点击外部、窗口变化或 Esc 只关闭当前最上层菜单。

## 映射抽屉

- 从右侧打开，宽 `min(450, 95%窗口宽)`。
- 来源区显示名称、标签和只读原始代码。
- 八类动作：快捷键、按键/组合键、媒体控制、音量控制、应用/文件、网址/协议、脚本/命令、手柄按键。
- 触发方式：单击、双击、长按 600ms、按下时、释放时。
- 默认勾选“屏蔽原输入”。该选项只有在全局映射开启后生效：已安全加载驱动时由内核处理可表示的键盘规则；否则只有普通键盘扫描码可使用明确标注的用户态兼容抑制。厂商 HID、Consumer Control 和手柄仍保持放行，不得显示成“已由驱动屏蔽”。
- 保存前执行快捷键、网址/已注册协议、现有文件及受支持脚本类型等格式校验；保存成功后立即更新节点外观、映射计数和顶部详情，并原子写入本地配置。
- 快捷键提供固定 2 秒录制；按键/组合键使用主页复制的版本化逻辑目标。键盘扫描码与纯键盘组合可由 `SendInput` 输出；厂商 HID 与手柄输出会在保存前明确拒绝。媒体与音量使用专用选择控件。

## 方案与应用自动切换抽屉

- 从侧栏“管理”入口打开，宽 `min(520, 95%窗口宽)`；与映射抽屉共用遮罩，Esc 只关闭最上层抽屉。
- 可复制所选方案、重命名，并把所选方案设为未匹配软件使用的默认编辑方案。
- 规则行由“进程名称 → 方案”组成；接受裸进程名、可选 `.exe` 或完整路径，保存时拒绝规范化后的重复名称和不存在的方案。
- 显示 KeyPilot 获得焦点前最近一次检测到的外部前台进程，并提供一键添加。自动切换关闭、进程未匹配或进程读取失败时使用默认方案。
- 前台变化只切换内存中的生效配置，不自动写盘；方案和规则仅在用户明确保存时持久化。
- 保存期间锁定抽屉并继续使用上一份已确认配置；只有原子保存成功后草稿才可参与前台自动切换。

## 原型中必须替换的演示行为

- 浏览器 `keydown` 换成 Raw Input 键盘、限定 Raw HID、XInput 1.4 和后续驱动事件；当前不使用 GameInput。
- 可点击的手柄图形换成真实手柄状态。
- “模拟捕获特殊键”和伪造 HID 字符串必须删除。
- 示例映射、设备名称、服务状态、错误数和电量不得冒充真实数据。
- 应用/文件与脚本仍可后续增加原生文件选择器；当前快捷键、媒体、音量和复制按键目标已经使用专用交互。
- Esc 只关闭最上层浮层，并把焦点还给来源节点。
